First stable release of **PuskarUIN**: internships, jobs, and career events from Pusat Karier UIN Jakarta in one app.

### Highlights
- **Jobs and internships:** search, type filter, sort by deadline or newest, and a detailed job page with key facts, qualifications, benefits, and company profile
- **Career events** split into upcoming and past, with online/offline filter, add to calendar, and share
- **Reminders** one hour before an event starts; tapping the notification opens the event
- **Saved** tab for bookmarked jobs and active reminders
- **Settings:** light, dark, or system theme, and Material You dynamic color
- Works offline

### Install
Download `PuskarUIN-v1.0.0.apk` below and open it on your phone (Android 8.0 or newer). You may need to allow installs from your browser or file manager.
